01 Vision And Pillars

Status: partial

Spec

VibePinball v1 is a 3D web-native pinball game built around one polished classic physical table: Silverball Social. It should feel like a believable arcade cabinet that happens to run in a browser: real flippers, a real plunger lane, a strict ball simulation, visible table devices, mechanical audio, lamps, score chasing, and fast retries.

The v1 target is not a broad platform. It is a high-quality first table that can survive repeated play on stream and still feel fair, readable, and skillful.

Simulation first

The ball, flippers, table collision, ramps, lanes, bumpers, nudging, tilt, drains, and multiball interactions are authored as a physical system. Tuning may improve playability, but the game should not feel scripted or fake.

Classic arcade cabinet

The table theme is Silverball Social: a warm arcade hall and league-night table with polished wood, chrome, plastics, incandescent-style lamps, score inserts, a DMD-style display, and familiar pinball objects.

One polished table

All v1 work serves one complete table. More tables, an editor, mods, and cosmetic marketplaces are deferred until the first table is fun, stable, and complete.

Readable 3D

The player gets a fixed tilted cabinet view that keeps the full playfield visible. 3D depth, lighting, and cabinet presence must improve clarity rather than hide the ball or make shots hard to read.

Streamable runs

A normal game should last about 3-5 minutes across three balls. Restarts are instant, scoring is visible, multiball creates a strong highlight moment, and the final score is easy to compare.

V1 success criteria

  • A new player can launch the game, start a three-ball session, operate the table, and understand the current score without instructions outside the game.
  • A skilled player can intentionally aim at lanes, ramps, targets, and lock shots.
  • Nudging is useful but risky, with visible warnings and an actual tilt penalty.
  • Lock and multiball are reachable in normal play and feel like the table centerpiece.
  • Scores persist locally and can be submitted to a global leaderboard with server-side sanity checks.
  • The 3D scene is nonblank, correctly framed, and responsive across supported browser viewports.
