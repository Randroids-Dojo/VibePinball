05 Scoring And Rules

Status: partial

Spec

Silverball Social uses classic-simple pinball rules with one modern centerpiece: lock and multiball. The rules should be understandable from the table lights and DMD messages without a manual.

Three-ball game

A session starts with ball one, awards bonus after each drain, serves balls two and three, then ends with final score, initials entry if eligible, and leaderboard submission flow.

Base scoring

Bumpers, slings, lanes, rollovers, targets, ramps, orbit shots, skill shots, locks, jackpots, bonus, and multiball events each award explicit point values.

Skill shot

The analog plunger can land the ball in a lit skill-shot lane. The DMD announces the award and the table lights reset for normal play after the attempt is made or missed.

Target progress

Completing the target bank advances lock qualification. Target state is visible through inserts or target changes and survives until the current lock stage completes.

Ball lock

Once qualified, a lock shot captures a ball or records a virtual lock if physical capture would harm play pacing. The table clearly shows lock count and serves the next ball when needed.

Multiball

After enough locks, multiball launches multiple active balls, lights jackpots, plays heightened feedback, and ends when only one ball remains active.

Jackpots

During multiball, lit major shots award jackpots. Completing enough jackpots can light a super jackpot, but v1 keeps the sequence short enough for normal players to see it.

Bonus count

After each non-tilted drain, the table counts bonus from lanes, targets, bumpers, and mode progress. Tilt cancels bonus for that ball.

Tilt penalty

Tilt disables flippers and scoring for the current ball until it drains. The next ball begins normally with tilt warnings cleared.

Difficulty target

The default tuning is fair but demanding. New players should last a few minutes, while accurate shots, controlled catches, plunger skill, and nudge discipline produce meaningfully better scores.
