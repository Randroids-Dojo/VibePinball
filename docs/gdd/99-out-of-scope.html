99 Out Of Scope

Status: not_started

Spec

This file is the v1 scope fence. The loop must not add these items without explicit approval, even if they are attractive or common in pinball games.

No table editor

v1 does not include a table editor, layout editor, scripting tool, device palette, or public creation workflow.

No multiple tables

v1 ships Silverball Social only. Second tables, themed variants, and alternate layouts are deferred.

No mods or marketplace

v1 does not include mods, skins marketplace, user-generated assets, table sharing, or paid cosmetic systems.

No deep wizard rules

v1 avoids layered modern mission stacks, long wizard-mode chains, complex mode stacking, and rule depth that distracts from making the core table feel excellent.

No cabinet service simulation

v1 does not simulate coin doors, operator menus, service diagnostics, mechanical maintenance, or real-money arcade operation.

No replay-verified leaderboard

v1 uses server sanity checks for leaderboard integrity. Full replay capture, deterministic replay verification, and anti-cheat adjudication are deferred.
